# Arkansas Home Mortgage 1003 Android App — v1.0.0

Ready-to-upload Android project for the Arkansas Home Mortgage residential mortgage application prototype.

## Branding
- Arkansas Home Mortgage NMLS ID 2560263
- Mark Wilson NMLS# 641232
- Welcome headline: **Apply For Your Home Loan**
- Website: https://www.arkansashome.mortgage

## Upload to GitHub
Upload the contents of this folder to the root of `meetmarkwilson/AHM1003`, commit to `main`, and GitHub Actions will build a debug APK automatically.

## Download the APK
After the workflow completes: GitHub → Actions → Build Arkansas Home Mortgage APK → latest run → Artifacts → `ArkansasHomeMortgage-1003-v1.0.0-debug`.

## Important
This is a prototype. Do not use it to collect live consumer NPI/financial data until authenticated encrypted backend storage, secure transmission, required disclosures/consents, audit logging, retention controls, identity verification, e-signature, and validated URLA/ULAD/LOS integration are implemented and reviewed for compliance.
